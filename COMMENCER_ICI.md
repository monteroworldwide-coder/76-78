# Portail 76–78 Champs-Élysées — mise en ligne

Ce dépôt est initialisé mais le code de l'application doit encore être importé. Ne pas considérer le site comme publié.

1. Télécharger l'archive du projet fournie dans notre conversation ChatGPT et la décompresser sur votre ordinateur.
2. Sur cette page GitHub, choisir « Add file » puis « Upload files » et glisser **le contenu** du dossier décompressé. À la racine doivent se trouver `render.yaml`, `package.json`, `server.mjs`, `public/` et `scripts/` (pas seulement un fichier ZIP ni un sous-dossier).
3. Vérifier que le commit existe et que l'action de vérification est verte, puis ouvrir Render, « New > Blueprint », sélectionner ce dépôt et lire le récapitulatif du tarif avant validation.
4. Configurer les secrets `ADMIN_USER` et `ADMIN_PASSWORD` dans Render, **jamais dans GitHub**. Ne pas publier de données personnelles privées. Compléter les mentions légales et le RGPD avant la diffusion publique.
